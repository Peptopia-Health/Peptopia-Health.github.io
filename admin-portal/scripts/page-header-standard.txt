# THE STANDARD HEADER / BANNER — Peptopia Health
Approved by David, November 20, 2026. **Required reading before building ANY new material** (GUIDE_BUILD_SCRIPT §53 points here). The standard was built once, on the Shipping & Tracking page; every new page copies this construction and changes only the named attributes (tagline text, icon functions, palette color where a page family requires it).

## THE DEFAULT RULE (David, Nov 20, 2026)
- Assume this header applies to ALL new material.
- ALWAYS ASK David whether the header should appear or not — some material takes no header (e.g., files made for his workplace). Ask; never silently include it and never silently omit it.

## THE CHANGE PROCESS (David, Nov 20, 2026, PERMANENT)
Never change the header/banner on any page without (1) listing the change, (2) showing a mock-up page IMAGE in chat, and (3) gaining David's approval first. A live preview link may accompany the image, never replace it.

## CONSTRUCTION (the approved spec)
One line, vertically centered, `display:flex; align-items:center; justify-content:space-between`:
- LEFT — brand: the Peptopia logo medallion (IMG_3345) at 46px (38px ≤640px, 34px ≤400px), border-radius:50%, pink glow shadow `0 0 10px 2px rgba(236,72,153,.55), 0 0 26px 8px rgba(236,72,153,.18)`; then the wordmark block.
- WORDMARK: `PEPTOPIA` — Outfit 800, .82rem, letter-spacing .14em, color #1e1b4b (dark theme #f1f5f9). Tagline beneath — .48rem, 600, letter-spacing .3em, color #5B6B82 (dark #94a3b8), ALL CAPS, its lines HUGGING the line above (line-height inherits the wordmark's 1.15; NEVER add line-height to the tagline). Shipping page tagline: `SHIPPING<br>& TRACKING`.
- LOGO RULE: the light-theme logo (IMG_3345, dark medallion) is used in BOTH themes. No light/dark logo swap (David, Nov 20, 2026 — supersedes the earlier swap behavior for this header).
- RIGHT — round icon buttons, ONE uniform gap (.55rem desktop, 5px mobile), all the same size (38px desktop, 34px ≤640px, 32px ≤400px), vertically centered on the brand's line. Shipping page order (since Nov 20, 2026): Admin, Tracking, print, theme toggle. A page's icon set may differ; the construction may not.
- ICON RENDER: each icon is an IMAGE button — the master file itself, `border-radius:50%`, round soft shadow `0 8px 14px rgba(15,23,42,.30), 0 2px 4px rgba(15,23,42,.25)`. An icon on a square or white plate is a defect. `filter:drop-shadow()` is banned; the glisten is part of the source art and is never recreated.
- THEME TOGGLE: swaps the page's `data-theme` (this page family) or `html.dark` (guide family) — CSS swaps the moon/sun images; the toggle's JS must never overwrite the button's innerHTML (the old emoji-swap line broke the image button; it is removed wherever this header is installed). Page-specific legacy sizing on `#themeBtn` is overridden by `#themeBtn.peptopia-iconbtn{width:38px;height:38px}` (+ responsive steps) — a 52px toggle among 38px icons was a real defect caught by measuring.
- PRINT: icon buttons hidden in print.
- ALWAYS build and render-verify at desktop AND mobile widths, light AND dark themes, before showing David.

## HOW THIS STANDARD WAS REACHED (the steps — consult before improvising)
1. Draft 1 (Nov 20, ~3:20 AM) copied the Admin Portal's header files — WRONG masters: the portal's btn-print.png/btn-moon.png are the flat solid rebuilds; icons read as dull squares. LESSON: the portal is not the icon source; the holo masters in your_files are.
2. David's corrections: tagline lines must hug (a line-height:1.6 addition had spread them); icons must be the round glassy shiny circles, evenly spaced; & TRACKING in all caps.
3. Draft 2 used the true holo masters (btn-print-turq / btn-moon-holo / btn-sun-holo). Measuring the render caught the page's legacy #themeBtn rule inflating the toggle to 52px — fixed with the ID+class override. LESSON: measure icon geometry; never trust eyeballing.
4. David renamed the page: it is Shipping & TRACKING, not Shipping & Pharma — portal link, page title, and generator all corrected.
5. David on the moon: the original master's yellow was flat, dull, opaque — "dirty yellow." The printer is the style reference: holographic, see-through. Moon + sun were re-rendered (image edit of the masters, shapes locked): translucent holographic #F0F000 fill, thin neon yellow outline, single thin neon yellow rim replacing the magenta double rim. A first sun pass came back hollow (outline only) and was re-run to add the translucent fill. The generated art's white background was re-cut to transparency by circle detection. A hand-rolled pixel edit was tried first and REJECTED (muddy olive fill, doubled edges, hazy rim) — do not hand-edit these masters pixel-by-pixel; evolve them with the image-edit route and lock shapes in the instruction.
6. David: the logo must NOT swap on dark theme — the light-theme logo stays. Logo swap removed.
7. Draft 3 approved as "the best so far" but the yellow still read dull → the glow push (programmatic, color-only): masked the yellow family, lifted value ×1.55 with hot cores toward near-white yellow, screen-blended a blurred bloom, and let a soft halo fall outside the disc edge. RGB of fully transparent pixels zeroed (some viewers flatten transparency onto stored RGB).
8. David approved the mock-up Nov 20 ("Perfect mock-up") and ordered: replace the live file, patch the generator, document everything, and apply the default rule + ask-first rule above. The new moon/sun replaced the masters in your_files the same day.
9. The two placeholder buttons then got their functions (David, Nov 20): one → Admin Portal with a NEW standard admin graphic; the other → the tracking view (the Admin Portal's Shipments panel) with a NEW standard tracking graphic. Both icons were built the standing way — copy the approved template disc, change only the glyph and the neon color — never drawn from scratch. Mock-up v5 (same preview URL) showed the family unified in light + dark.
10. David on v5: "Nearly perfect" — one exception: the dark-theme sun read SOLID. Fixed by the alpha rebuild recorded under the Sun master above (step: diagnose alpha first — the art was fine, the translucency was gone). He then ordered the install completed: masters to your_files, 256px embeds to the generator's assets, build_report.py patched (placeholders replaced by the two link buttons with __ADMIN_URI__/__TRACK_URI__), live page regenerated + published + md5-verified Nov 20, 2026.
