🎨 Palette Tokens

One palette, defined once as CSS tokens (--pal-*) so a single change flows through every build. Colors are copied character-for-character from David's palette — never rebuilt from memory. These are the effect colors of the kratom guides (GUIDE_BUILD_SCRIPT §9) and the accents the rest of the site draws from.

Energy
--pal-energy · #FFFFFF

White effect figures in every kratom guide — picker circles, pies, dots. Always carries a grey border, or it vanishes on light pages.

Focus
--pal-focus · #F06000

Tangerine. The Focus effect everywhere, and the picker's target satellite. Any tangerine anywhere is exactly this hex — verified, never approximated.

Mood
--pal-mood · #10C000

The Mood effect green — guide pies, bars, dots, table cells, and picker circles.

Calm / Gold
--pal-calm · #F0F000

The Calm effect — and the gold of the Kratom Reviews leaf border (David's pick, Nov 6) and the highlighter family.

Pain
--pal-pain · #E01020

The pain effect red. On the picker wheel the Pain satellite's disc is this red — its cross is always bright neon green #2BFF5C, never red.

Sleep
--pal-sleep · #0A0A0A

The Sleep effect black. Carries a grey outline where it would vanish on dark backgrounds. Never the default icon color.

Cobalt
--pal-cobalt · #0070D0

The default icon color when nothing else claims the icon. The picker hub's leaf wears it, and it is the variation bead's neon.

Purple
--pal-purple · #6C4FE0

Theme purple for the nursing-family accents. It was the Kratom Legality theme until Nov 16, 2026, when Neon Leaf replaced it — blues and magentas stay far apart.

💎 Icon Masters

The Homepage Rule: copy the source, never recreate. The only things that ever change are (1) the color — almost always a neon hue that glows — and (2) the image inside, sized almost as large as its circle without touching the borders. The glisten is part of the copied source and is never redrawn; a soft smudge in its place is a defect. Masters live in ~/workspace/your_files/ and every new icon is derived from them, then saved back as a master.

📚 Build References

The governing docs behind every build. The scripts live on the workstation (named plainly below); what is linkable on the site is linked.

GUIDE_BUILD_SCRIPT

The bible. Every guide build or update runs it end-to-end — responsive and print standards included — and no guide publishes until the checker passes.

  • §9 — the Effect–Color Standard (the tokens above)
  • §10A — the Homepage Rule: copy the source, never recreate
  • §10B — short last rows center on the page
  • §24 / §25 — responsive + print-to-PDF standards
  • §30H — plant guides; sources print as a bulleted list

Local doc: ~/workspace/guide-build/GUIDE_BUILD_SCRIPT.md

check_guide.py

The pre-publish gate. Run it on every guide file before publishing — a PASS is required, in both themes, at phone and desktop sizes, with print verified.

Local tool: ~/workspace/guide-build/check_guide.py

Banner Standard

Banner buttons are the logo itself, never rebuilt as CSS: the printer in turquoise hologram, the theme pair (moon + sun) in lemon hologram. The dark-theme logo interior is magenta-pink glass with the figure and lettering dark and sharp.

Local standard: ~/workspace/banner-deploy/ · masters in the gallery above

Admin Button Standard

Every Admin Portal button copies the homepage .btn verbatim — raised, glossy push buttons, one uniform width set by the longest button, hover brighten, press-down. Dark text on light gradients; never white text on orange.

Lives in: the Admin Portal source + MEMORY.md
