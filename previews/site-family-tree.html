How to read this tree

  • Parent = first linker. A page's parent is the first page, in crawl order (Admin Portal tree before X-Peps tree), whose links point to it. Every linked page appears exactly once; extra inbound links are shown as small “also linked from” tags.
  • The homepage is a leaf, not a root. The holder homepage links nowhere, so the site's real descent runs through the two hubs beside it.
  • Method note: links are static links resolved against the page inventory; JavaScript-injected navigation, portal card scripts, and links in emails are not captured — so “unlinked” means no static inbound link, not “unreachable in practice.”
